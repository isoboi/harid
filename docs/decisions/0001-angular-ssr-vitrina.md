# 0001 — Витрина Харида: отдельный проект на Angular SSR
Дата: 2026-11-17   Статус: принято

## Контекст
Текущая витрина harid.vercel.app написана на Next.js и не обращается ни к
какому API: лавки, товары и фото (Unsplash) зашиты в код. Бэкенд (`distributor`)
уже отдаёт публичный контракт `/api/market/*` из «Товаров» и «Заявок»
(решение 0004 бэкенда): каталог, оформление заказа, вход покупателя по SMS,
трекинг, регистрация лавки по SMS-коду. Тексты текущей витрины обещают другую
модель (онлайн-оплата, деньги хранятся у Харида, подключение Instagram через
OAuth), которой больше нет. Нужен фронтенд, работающий с реальным API.

## Решение
- Новый отдельный проект `disti/harid` на Angular (standalone, signals) с SSR.
  Страницы лавки и товара рендерятся на сервере — у ссылок в Telegram и
  Instagram есть превью с фото и ценой (Open Graph), страницы видны поисковикам.
- Объём: часть покупателя (главная, категория, лавка, товар, поиск, корзина,
  оформление, вход по SMS, «Мои заказы», трекинг, избранное) и `/sell` —
  регистрация лавки по SMS-коду в два шага. Кабинет лавки — в админке
  (`distributor-admin`), здесь его нет.
- Тексты переписываются под действующую модель: оплата наличными курьеру,
  без предоплаты, проверка при курьере. Онлайн-оплаты, хранения денег у Харида
  и OAuth-подключения Instagram на витрине нет.
- Визуальный стиль и структура страниц — по текущей harid.vercel.app.

## Отклонённые варианты
- **Angular SPA (только клиентский рендер).** Проще и дешевле в хостинге, но
  ссылки на товар в мессенджерах без превью, поисковики видят пустую страницу.
  Продажи лавок идут через ссылки из Instagram и Telegram — это главный канал.
  Вернуться, если SSR станет узким местом по стоимости хостинга.
- **Оставить Next.js и подключить API.** Быстрее всего (дизайн готов), но два
  стека фронтенда в команде: админка на Angular, витрина на React. Владелец
  выбрал Angular.

## Последствия
- Нужен Node-хостинг для SSR (Vercel поддерживает Angular SSR); статического
  хостинга недостаточно.
- Код, выполняемый на сервере, не может трогать `window`/`localStorage` —
  корзина, избранное и токен покупателя живут только в браузере.
- Публичное API должно разрешать CORS для домена витрины.
- Старая витрина на Next.js выводится из эксплуатации после запуска новой.
