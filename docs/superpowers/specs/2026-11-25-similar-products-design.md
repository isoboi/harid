# Похожие товары — дизайн

Дата: 2026-11-25 · Размер: небольшая доработка

## Зачем

Покупатель открыл товар, а он не подошёл: дорого, нет его размера, нет в наличии. Блок «Похожие в других лавках» показывает почти то же самое у других продавцов, чтобы покупатель не ушёл с сайта.

## Цели

- На странице товара показать до 8 товаров той же категории из **других** лавок.
- Сначала показывать то, что реально подходит на замену: в наличии, с выбранным размером, по близкой цене.

## Не цели

- Доработка бэкенда (эндпоинт `/products/:id/similar`). Если он появится, поменяется только источник данных.
- Подбор по словам из названия: подписи из Instagram для этого слишком шумные.
- Похожие товары той же лавки: для них уже есть блок «Ещё в лавке».

## Анти-цели

- Пустой заголовок или одна одинокая карточка: если подходящих товаров нет, блока нет совсем.
- Повтор товаров из «Ещё в лавке»: текущая лавка исключается целиком.
- Блок, из-за которого страница товара открывается дольше: ошибка или медленный ответ не мешают показу товара.

## Подходы

| | Суть | Плюсы | Минусы |
|---|---|---|---|
| 1 | До 24 товаров категории, без текущей лавки, в порядке сервера | Самое простое | Альтернатива может быть в 10 раз дороже |
| **2 (выбран)** | Тот же запрос, пересортировка на клиенте: наличие → размер → близость цены | Подборка «почти то же самое», без бэкенда | Выбор только из 24 свежих товаров категории |
| 3 | Эндпоинт `/products/:id/similar` в `distributor` | Лучшая подборка по всей базе | Нужна работа на бэкенде, его актуальный код недоступен |

Выбран вариант 2: пользователь хочет, чтобы покупатель нашёл замену, а для этого важны наличие, размер и цена.

## Решения

**Запрос.** Когда товар загружен и у него есть `category`, страница вызывает `api.products({ category, limit: 24 })`, параллельно с «Ещё в лавке». Ошибка превращается в пустой список (`catchError(() => of([]))`), как у соседних запросов. Товар без категории ничего не запрашивает. Запрос идёт и на сервере, как «Ещё в лавке»: ссылки на другие товары в HTML полезны для поисковиков.

**Подбор.** Чистая функция `rankSimilar(list, product, size)` в `src/app/shared/similar.ts`:
1. Убирает текущий товар и все товары лавки `product.shop_handle`.
2. Сортирует по ключам по очереди:
   - в наличии раньше, чем нет в наличии;
   - если покупатель выбрал размер: товары с этим размером (или вообще без размеров) раньше остальных;
   - по `|price − product.price|` по возрастанию; товары с `price: null` (цена в Direct) идут в конец; если у текущего товара нет цены, этот ключ не учитывается;
   - при равенстве сохраняется порядок сервера (стабильная сортировка).
3. Возвращает первые 8.

Список на странице — `computed` от сырого ответа и сигнала `size()`: при выборе размера подборка пересобирается без нового запроса.

**Показ.** Заголовок «Похожие в других лавках», сетка `app-product-card`, как в «Ещё в лавке». Блок выводится, только если в подборке **не меньше 2 товаров** (это решение исполнителя, его можно пересмотреть).

**Место.**
- Товар в наличии: под «Ещё в лавке», в самом низу страницы.
- Товара нет в наличии (`!p.in_stock`): во всю ширину сразу под карточкой товара (фото и колонка с ценой и кнопками), над отзывами. В этот момент замена нужнее всего. Внутрь колонки с кнопками блок не ставится: сетке из 8 карточек там на десктопе тесно. «Ещё в лавке» остаётся на своём месте.

**Сброс.** При переходе на другой товар подборка очищается вместе с `more`, а запрос отменяется в `onCleanup`, как у остальных вложенных запросов.

## Оставлено исполнителю

- Отступы блока в верхнем положении (для товара не в наличии): в стиле соседних элементов колонки `info` или во всю ширину под `layout`, по тому, что выглядит аккуратнее на телефоне и десктопе.
- Скелетон для блока не нужен: он появляется после товара и не сдвигает то, что выше.
- Тесты: спека `rankSimilar` (исключение лавки и товара, порядок по наличию, размеру и цене, `price: null`, стабильность, лимит 8) и правки спеки страницы товара (нет категории → нет запроса; меньше 2 товаров → нет блока; не в наличии → блок наверху; ошибка API → страница работает).
