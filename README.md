# Харид — витрина

Публичная витрина маркетплейса Харид (Таджикистан, Душанбе): каталог товаров, магазины, корзина, оформление заказа с оплатой наличными и личный кабинет покупателя. Построена на Angular 19 с SSR.

Бэкенд — сервис distributor (по умолчанию `http://localhost:3000/api`, см. `src/environments/environment.ts`).

## Команды

```bash
npm install        # зависимости
npm start          # dev-сервер на http://localhost:4200/
npm test           # юнит-тесты (jest)
npm run build      # продакшн-сборка в dist/harid (браузер и сервер)
```

## Запуск SSR

После `npm run build` серверная часть запускается командой:

```bash
node dist/harid/server/server.mjs
```

По умолчанию сервер слушает порт из переменной окружения `PORT` (или 4000).

Сервер принимает запросы только с разрешённых Host: `localhost` и `127.0.0.1` разрешены всегда, остальные задаются переменной `NG_ALLOWED_HOSTS` (через запятую). **Это обязательная переменная деплоя:** если боевого домена в ней нет, SSR-сервер отвечает HTTP 400 на ВСЕ страницы. При `NODE_ENV=production` и пустой переменной при старте выводится предупреждение. Продакшн: `NG_ALLOWED_HOSTS=harid.tj,www.harid.tj node dist/harid/server/server.mjs`.

## Аналитика

Яндекс.Метрика. Номер счётчика (только цифры) — `metrikaId` в `src/environments/environment.prod.ts`; пусто — аналитика выключена (так и в разработке). Не работает на сервере и при включённом в браузере «Не отслеживать».

Автосбор Метрики (карта кликов, вебвизор, отслеживание ссылок) выключен намеренно: он отправляет адрес страницы как есть, а в адресе заказа (`/order/…?t=…`) лежит токен доступа. Просмотры страниц шлёт `Analytics.pageview` с очищенным адресом: без query и номера заказа, остаются только UTM-метки.

В Метрике создайте цели типа «JavaScript-событие» с этими идентификаторами:

| Событие | Когда |
|---|---|
| `view_product` | открыта страница товара |
| `add_to_cart` | товар добавлен в корзину |
| `begin_checkout` | открыто оформление с товарами в корзине (раз за визит) |
| `purchase` | заказ оформлен (параметры: сумма, число товаров и лавок — без имени, телефона и адреса) |
| `share` | «Поделиться» (параметр `method`: `native`, `telegram`, `whatsapp`, `copy`) |
| `direct_click` | «Написать в Direct» у лавки без подключения |
| `seller_signup` | лавка открыта на странице «Продавцам» |

Источники трафика видны по UTM-меткам: `utm_source=share&utm_medium=telegram|whatsapp|copy|native` — кнопка «Поделиться»; `utm_source=instagram&utm_medium=bio` — ссылка из шапки профиля лавки (её показывает страница «Продавцам» после открытия лавки).

## Поиск (SEO)

- `/robots.txt` и `/sitemap.xml` отдаёт SSR-сервер (`src/server.ts`) для любого Host из `NG_ALLOWED_HOSTS`. Sitemap собирается из API (категории, лавки, товары), кэшируется на 10 минут; если API недоступен целиком — ответ 503, а не пустой файл. В robots.txt закрыты корзина, оформление, заказы, вход, личные разделы, чаты и поиск.
- `canonical`, `og:url`, `og:type`, `twitter:card` и JSON-LD (товар с ценой в сомони и наличием, лавка, сайт с поиском) строятся от адреса запроса — боевой домен нигде не зашит. За обратным прокси должен приходить `X-Forwarded-Proto`; в продакшне для любого хоста кроме localhost схема принудительно `https`.
- Настройте редирект `www` → без `www` (или наоборот): canonical у каждого хоста указывает на него самого.
- После запуска добавьте сайт в Яндекс Вебмастер и Google Search Console и укажите `https://<домен>/sitemap.xml`.
